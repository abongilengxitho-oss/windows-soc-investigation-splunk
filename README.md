# Windows SOC Investigation — Event ID 4798

## Overview

This project documents a home Security Operations Center (SOC) investigation using Splunk to analyze Windows Security Event ID 4798.

The investigation focuses on identifying patterns of local group membership enumeration, analyzing affected accounts and processes, establishing an event timeline, and producing a SOC-oriented triage view.

The project was completed in a controlled home lab environment for cybersecurity learning and portfolio development.

---

## Objectives

The objectives of this investigation were to:

- Collect and analyze Windows Security logs in Splunk
- Investigate Windows Security Event ID 4798
- Identify accounts associated with the activity
- Analyze event frequency and temporal patterns
- Identify processes associated with the events
- Identify the affected host
- Create a basic SOC triage view
- Document findings and security recommendations

## Event Investigated

### Windows Security Event ID 4798

Event ID 4798 represents:

> A user's local group membership was enumerated.

This event can be generated by legitimate Windows activity as well as activity that may warrant further investigation.

Therefore, the presence of Event ID 4798 alone was not treated as proof of malicious activity.

---

## Investigation Methodology

The investigation followed a basic SOC workflow:

1. Identify relevant Windows Security events
2. Review raw event data
3. Analyze account frequency
4. Establish a timeline of activity
5. Identify associated processes
6. Identify the affected host
7. Review an individual event in detail
8. Aggregate the results into a triage-oriented view
9. Assess the activity and identify areas for further investigation

---

## Findings

### Account Activity

Event ID 4798 activity was observed across several accounts, including:

- MANDILAKHE_N$
- ngxit
- Administrator
- DefaultAccount
- Guest
- SE-Account
- WsiAccount
- WDAGUtilityAccount

The computer account `MANDILAKHE_N$` generated the highest observed event volume, followed by the `ngxit` account and several built-in Windows accounts.

### Process Activity

The investigation identified Windows system processes associated with the observed Event ID 4798 activity.

Process analysis was performed using SPL extraction and statistical aggregation.

### Timeline

The activity occurred intermittently rather than continuously.

Several periods contained elevated event volumes, demonstrating bursts of local group membership enumeration activity.

### Host

The investigation identified the Windows endpoint generating the observed Event ID 4798 events.

---

## Security Assessment

The observed Event ID 4798 activity should not automatically be classified as malicious.

The investigation identified repeated local group membership enumeration, but additional context would be required to determine whether the activity represents normal Windows behavior, administrative activity, software behavior, or potentially suspicious enumeration.

Further correlation with authentication events, process execution events, and other Windows Security events would improve confidence in the assessment.

## Recommendations

Based on the investigation, recommended next steps include:

1. Establish a baseline for normal Event ID 4798 activity.
2. Monitor unusual increases in enumeration activity.
3. Correlate Event ID 4798 with authentication and process execution events.
4. Investigate unexpected processes associated with enumeration.
5. Monitor privileged and administrative accounts.
6. Investigate activity occurring outside expected administrative windows.
7. Develop correlation rules combining multiple Windows Security events.
